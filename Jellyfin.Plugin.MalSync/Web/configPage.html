MyAnimeList access

One MyAnimeList application is shared by everyone on this server. Each user still signs in with their own MAL account.

ⓘ
Creating the application
Open myanimelist.net/apiconfig, create a client, set App Type to other and App Redirect URL to exactly http://localhost, then paste the Client ID below. A wrong redirect URL is the most common reason sign-in fails.
